# posts/

Drafts for the publishing thread — one substantive post per stage, following the anatomy the roadmap sets out: **pain → decision → demo → lesson.**

**Everything in here is a draft, and drafts are not what gets published.** Each one is assembled from the Decision Log and the audit, with the real numbers pulled from the repository so the argument has evidence under it rather than adjectives. Amjed rewrites it in his own voice before it goes anywhere.

That step is not a formality. These posts are about judgment — which merges were refused, which measurement was overruled, what a constraint cost. An agent-written post about judgment is the wrong artifact no matter how accurate it is, because the thing being demonstrated is whose judgment it was.

So: the draft supplies the structure, the numbers and the citations. The voice, the framing and anything that reads as a claim about the author are his.

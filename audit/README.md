# audit/

Audit documents — the assessments written *before* an intervention, as they would be written for stakeholders.

**What belongs here:** inventories, findings with severity, priorities, and recommendations. Written in the voice of someone reporting to a team that has to act on it.

**What does not belong here:** decisions. When an audit finding turns into a call about what the system will do, that call goes to [`decisions/`](../decisions/) with its options and trade-offs. The audit says *what is true and what it costs*. The Decision Log says *what we chose and why*.

The distinction matters: an audit that recommends is still an audit, but an audit that quietly decides has skipped the step where the reasoning gets recorded.
